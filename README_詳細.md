# 3D Binaural Audio Sequencer (BB-Sequencer) - SOFA Edition

Studio One（DAW）のようなマルチトラック音声編集機能と、MMD（MikuMikuDance）のようなキーフレーム方式の3D空間制御を組み合わせた、デスクトップ向け高品質バイノーラル音響制作アプリケーションです。

---

## 🌟 主な機能

### 1. 高品位 SOFA / HRIR カスタム畳み込みバイノーラルエンジン
- **内蔵 Neumann KU100 ダミーヘッドモデル**:
  - 人体音響特性（頭蓋半径 \(r=8.75\text{cm}\) の Woodworth-Schlosberg ITD両耳間時間差モデル、反対耳の頭部音影遮蔽ILD、および仰角・前後判定のための耳介ピンナ共振ノッチ）を精密に計算した高解像度インパルス応答データセット。
- **SOFA / HRIR ローダー**:
  - AES69 標準 SOFA 形式（NetCDF）、HRIR JSON形式、およびステレオWAVインパルス応答ファイルの読み込みに対応。
- **基底2 FFT / Overlap-Save 畳み込み**:
  - 音源のXYZ座標（方位角・仰角・距離）から最適な左右インパルス応答を取得し、周波数領域で高速・高精度に畳み込み。
  - 音源移動時の不連続・クリックノイズを防止する **イコールパワー・コサインクロスフェード処理** を搭載。

### 2. RAM プレビュー（バックグラウンドキャッシュレンダリング）
- タイムライン上部に動画編集ソフト風の **「RAMレンダリングバー」**（緑色＝キャッシュ完了、黄色＝レンダリング中、灰色＝未レンダリング）を表示。
- タイムライン全体の最高品質バイノーラル音声をバックグラウンドでプリレンダリング。
- キャッシュ済み区間は、CPU負荷ゼロ・音飛びゼロ・レイテンシーゼロで最高品質の空間音響を直接試聴可能。
- キーフレームやクリップの編集を検知し、該当区間を自動的にインバリデート。

### 3. Studio One 風 DAW タイムライン
- **トラック管理**: トラックの追加・削除、名前変更、カラーリング。
- **ミキサー制御**: 各トラックに Mute（消音）、Solo（ソロ再生）、Volumeスライダーを装備。
- **クリップ操作**:
  - ローカルの音声ファイル（WAV, MP3, OGG 等）の読み込み。
  - ワンクリックで空間定位テスト用のアルペジオ音声を生成する「テスト音生成」ボタン。
  - クリップのドラッグ移動（開始フレームの調整、フレームスナップ）。
  - クリップ左右端のドラッグによるトリミング（開始位置・終了位置のカット）。
  - 各クリップの波形（Waveform）ピーク描画。
- **時間軸ルーラー**: 秒数・フレーム数表示、クリック・ドラッグによるシーク、ループ領域の可視化。

### 4. Three.js による3D空間ビューワ
- **リスナー頭部 & 耳マーカー**:
  - 原点固定のダミーヘッド（+Z方向を向くノーズインジケータ付き）。
  - 左右の耳の位置 `(-0.0875, 0, 0)` [緑 / L]、`(+0.0875, 0, 0)` [赤 / R] を視覚化。
- **トラック音源球体 & ギズモ操作**:
  - トラックカラーに対応した音源オブジェクト。
  - 選択中トラックには `TransformControls` 移動ギズモがアタッチされ、ビュー上で直接ドラッグして現在フレームのXYZ座標を変更可能。
- **カメラ視点プリセット**:
  - パースペクティブ（全体俯瞰）
  - 上面（Top: Y+真上から）
  - 正面（Front: Z前方から）
- **HUD座標表示**: 現在選択中のトラックの (X, Y, Z) メートル座標をリアルタイム表示。

### 5. MMD 風 キーフレームエディタ
- **フレーム番号グリッド**: 0, 5, 10, ... フレーム単位の目盛り表示（30fps / 60fps 切替対応、ズーム可能）。
- **ダイヤキーフレーム (◆)**:
  - Master (XYZ総合), Position X, Position Y, Position Z の個別チャンネル行。
  - キーフレームのクリック選択、ドラッグ移動、削除。
  - 座標の直接数値入力（X, Y, Z）。
- **補間エンジン**:
  - **Linear (線形補間)**: 一定速度での直線移動。
  - **Bezier (3次ベジェ加減速補間)**: 滑らかなイーズイン・イーズアウト（Cubic Ease-In-Out）。

### 6. プロジェクト管理 & WAVエクスポート
- **保存 / 読込**: トラック構成、クリップ情報、キーフレームデータを `.bbproj` (JSON) として保存・復元。
- **エクスポートエンジン切替**:
  - **SOFA 高精度畳み込み（デフォルト）**: 全フレームを高精度FFT畳み込みと距離減衰でオフラインレンダリング。
  - **Web Audio 標準 HRTF**: 軽量な標準 PannerNode によるバウンス。
- 48kHz 16-bit ステレオ PCM WAV としてローカルディスクへ書き出し。

## ⌨️ キーボードショートカット

| キー | 動作 |
|---|---|
| <kbd>Space</kbd> | 再生 / 一時停止 (Play / Pause) |
| <kbd>Ctrl + S</kbd> | プロジェクトの保存 (`.bbproj` JSON) |
| <kbd>Ctrl + E</kbd> | 3D空間軌跡データのCSV出力 (`.csv`) |
| <kbd>K</kbd> | 選択中トラックの現在フレームにキーフレーム (◆) を登録 |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | 選択中のキーフレームを削除 |
| <kbd>←</kbd> / <kbd>→</kbd> | 1フレーム前後にシーク |
| <kbd>Shift + ←</kbd> / <kbd>Shift + →</kbd> | 5フレーム前後にシーク |

## 🚀 起動・開発手順

### 開発モードの起動
```bash
npm run dev
```

### ビルド
```bash
npm run build
```

### Windows アプリケーションのパッケージング
```bash
npm run package
```
[`release/BB-Sequencer-win32-x64/BB-Sequencer.exe`](file:///d:/Apps/Binoral%20Editor/release/BB-Sequencer-win32-x64/BB-Sequencer.exe) が出力されます。

### 自動テストの実行
```bash
npm test
```
補間ロジック、Radix-2 FFT、Overlap-Save畳み込み、クロスフェード、HRIR空間探索、WAVバイナリ整合性テスト（全9件）が実行されます。
